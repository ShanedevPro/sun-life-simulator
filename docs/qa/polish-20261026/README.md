## 改了什么

- 26个无照片节点中，仅P03、A01、C01三个短章节标题保留黑场。18处叙事和5处章节回顾改用照片，制作22幅新图；U01与U02是同一次到达校园的连续镜头。

- 修正大学、毕业、创业的承接，补上申请受挫后的几年，消除2023与2024之间的日期倒退。Rainberry先解释身份，案件说明收在已读情节的来源菜单中。
- 逐场通读中文，缩短说明性正文。字幕使用均衡换行；高中机会段的末句再缩短，避免孤行。
- 逐图检查时拒绝了重复的竞拍姿势、空白或拉丁草写的小说稿、错误外套和课堂中复制的同事。另发现旧产品草图画成了手机硬件，修正该图和相关新图为聊天应用线框。
- 比较两种内置生图方案，选用成人主肖像与几种人生片段的照片蒙太奇。游戏标题和菜单仍是真实文字与控件。横版宣传图独立重新构图；不使用电影原海报或虚构获奖标志。
- README改为短介绍、在线入口、横版海报和三张实机图。[开发与维护](../../DEVELOPMENT.md) 和 [部署说明](../../../AGENT_DEPLOY.md) 保留完整工程步骤。
