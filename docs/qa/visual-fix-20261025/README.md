# 画面修订记录 · 2026-10-25

本轮按已确认的画面审查执行：毕业照视线、情节与动作对应、选择之后的反馈、平行人生的镜头差异，以及跨年代和连续镜头中的服装道具。

版本 1.0.1。120 个剧情节点、7 次主要抉择、8 个结局和 15 条完整路径均保留；选定照片由 52 张调整为 86 张。本轮新增或编辑 38 张，原来的 4 张退出当前选片。作者工作区保留旧图与生成原件。

剧情节点、分流、结局和存档版本保持不变。原始生成图片、提示词与退选记录保留在作者工作区，公开仓库只包含选定的 WebP 和本页摘要。

## 这次改了什么

- 毕业照直接修正双眼视线和镜片细节，保留人物与校园构图；毕业之后接上收拾宿舍的镜头。[手机画面](graduation-phone.jpg)
- 寄稿用装信封的手部动作；大学夜读、历史课堂和校园讨论各有对应画面。
- 创业段落区分选择前的讨论、开始新项目和团队运转，不再用同一张指着文件的照片连续交代结果。
- 平行人生用改稿、听取同事意见、交付、收到反馈等具体镜头展示选择后的变化。写字、核对资料、合上本子、往前走与起身离开都有自己的最后一幕。[结尾示例](ending-phone.png)
- 诉讼段落改用克制的工作画面。时间跳跃用黑场交代，不让跨年的叙述停在同一个动作上。
- 逐图检查发现的两处新问题也已修订：2021 年手机的屏幕开孔样式，以及连续公园镜头里的鞋子。较亮结尾照片上的小字加了轻微阴影。

现实主线原有 50 个带照片的节点、35 张不同照片，现为 51 个带照片的节点、46 张不同照片。重复使用由 15 次降为 5 次；相邻相同图片由 10 对降为 4 对。保留的是毕业去向前的停留、办公室衔接、同一顿晚餐和同一场香蕉活动。图片是否合理仍要看具体情节，不能只看数量。

所有完整路径中，原先最长连续三幕共用同一照片，现最多连续两幕；八个结尾都不再与前一幕共用同一文件。高中留校路线回到同一教室，以及互斥路线共用收拾行李照，保留了明确的复用理由。
